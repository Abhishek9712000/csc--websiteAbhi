# CSC Website

A Common Service Centre (CSC) website for Mayank Digital Studio.

## Features

- PAN Card Apply
- Aadhaar Services
- Passport Services
- Railway Ticket Booking
- Electricity Bill Payment
- Print & Xerox
- Online Form Filling
- Document Upload
- UPI Payment
- Track Application
- Admin Dashboard

## Technology Used

- React (Vite)
- Node.js
- Express.js
- MongoDB Atlas
- Render
- Vercel
